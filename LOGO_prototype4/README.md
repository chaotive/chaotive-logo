# Prototype 4 — Opposing CC system

- **Version:** 4
- **Created:** 2026-10-31
- **Based on:** Prototype 3
- **Status:** Preserved design exploration

## Direction

Prototype 4 turns the CC into a stronger standalone symbol. The crimson C opens inward from the left and the mirrored navy C opens inward from the right. Their opposing forms create a central field of tension while retaining the creative spark and chaos orbit.

## Changes from prototype 3

- Mirrored the right C so both letters face inward.
- Reduced and centered the CHAOTIVE wordmark to match the emblem width.
- Removed the special oversized red A.
- Gave every name letter equal scale.
- Alternated crimson and navy across the wordmark.
- Kept the established two-color palette instead of adding a third color.
