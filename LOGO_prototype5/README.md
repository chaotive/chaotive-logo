# Prototype 5 — Split-name Creative Chaos system

- **Version:** 5
- **Created:** 2026-10-31
- **Based on:** Prototype 3
- **Status:** Preserved design exploration

## Direction

Prototype 5 keeps prototype 3's favored CHAOTIVE lettering while giving the name and CC symbol a more explicit semantic system.

- CHAO is deep navy and TIVE is crimson, revealing two fused ideas inside the name.
- The first crimson C represents chaos through a broken orbit and displaced nodes.
- The second navy C represents creativity through a large spark and smaller spark points.
- The C colors invert the word halves they conceptually correspond to.
- The complete symbol group and wordmark share the same visual left and right guides within the square canvas.

## Changes from prototype 4

- Returned to prototype 3 as the primary lettering and composition reference.
- Grouped wordmark color by CHAO / TIVE instead of alternating every letter.
- Reassigned chaos to the first C and creativity to the second.
- Made the orbital and spark symbolism more explicit.
- Matched the symbol and brand widths as one square lockup.
