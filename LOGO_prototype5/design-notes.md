# Prototype 5 — Design notes

## Brand name

The wordmark preserves prototype 3's custom angular construction. Its color split now communicates the name's hybrid meaning:

- **CHAO** — deep near-black navy.
- **TIVE** — crimson red.

The A retains its distinctive shape but no longer receives a unique color.

## Symbol

The CC uses the inverse palette relationship:

- The first C is crimson and represents chaos. A broken orbital path and three displaced nodes create visible unstable motion.
- The second C is navy and represents creativity. One primary four-point spark and smaller spark accents make the creative meaning direct.

## Layout

The full CC symbol group and complete CHAOTIVE wordmark are stacked on shared left and right visual guides. The symbol remains taller, while both groups occupy the same intended width inside the square canvas.

This remains a raster prototype. A production vector redraw should lock both groups to mathematically identical bounds, refine the orbit, and normalize letter kerning at small sizes.
