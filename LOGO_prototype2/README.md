# Prototype 2 — Square-first A/C identity

- **Version:** 2
- **Created:** 2026-10-31
- **Based on:** Prototype 1
- **Status:** Preserved design exploration

## Direction

Prototype 2 turns the horizontal identity into a naturally square composition. A large crimson A interlocks with a near-black navy C above a compact CHAOTIVE wordmark, giving the studio an avatar-ready emblem while retaining prototype 1's palette and angular character.

## Changes from prototype 1

- Introduced a square-first stacked lockup.
- Separated the emblem from the full studio name.
- Simplified the silhouette for profile images, store tiles, and boot screens.
