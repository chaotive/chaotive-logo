- **Version:** 1

## Direction

The first redesign modernizes the original horizontal Chaotive logo while retaining its defining oversized crimson A, near-black navy lettering, angular geometry, and controlled collisions. It establishes the visual idea of creative chaos and the classic PC game studio influence.
